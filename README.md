## Description
A simple student admission page where applicants enter their details,
PHP saves them in MySQL, and all applicants are shown in an HTML table.

## Files
- `db.php` — database connection
- `admission.php` — form, logic, and applicant table
- `database.sql` — database + table creation
- `README.md` — this file

## Technologies Used
- PHP (object-oriented MySQLi)
- MySQL
- Bootstrap 5
- HTML / CSS

## How to Run
1. Import `database.sql` into phpMyAdmin
2. Copy the folder into XAMPP's `htdocs`
3. Start Apache and MySQL in XAMPP
4. Open: `http://localhost/admission_lab/admission.php`

## Expected Outcome
A styled admission form that saves applications
and displays them in a table below the form.
